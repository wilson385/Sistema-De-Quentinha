# 🍱 Sistema de Gerenciamento de Quentinhas

Sistema desenvolvido em **Python** para automatizar o registro de vendas de quentinhas, calcular o valor devido por cada cliente e obter o total das vendas.

## 🎯 Objetivo

O projeto foi criado para substituir um controle manual de vendas, reduzindo erros nos cálculos e facilitando o registro das informações dos clientes.

## ⚙️ Funcionalidades

* Cadastro da quantidade de pessoas.
* Registro do nome do cliente.
* Registro da quantidade de quentinhas compradas.
* Cálculo automático do valor da compra.
* Cálculo do total das vendas.
* Validação de texto e valores numérico.

## 💰 Regra de negócio

Cada quentinha possui o valor fixo de **R$ 16,00**.

O valor da compra é calculado através da fórmula:

`Quantidade de quentinhas × R$ 16,00`

**Exemplo:**

3 quentinhas × R$ 16,00 = **R$ 48,00**
